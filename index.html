Modo manual: toca una pieza y arrástrala para reubicarla. Usa “Girar seleccionada” para rotarla. Se impide colocar piezas fuera del tablero o encima de otra.

Cómo usar OptiCorte

  1. En Materiales, define dimensiones del tablero, espesor del disco (kerf) y margen de seguridad.
  2. En Piezas, registra largo, ancho, material y cantidad.
  3. En Optimizar / plano, ejecuta la optimización automática.
  4. Selecciona cada tablero para revisar el plano. Arrastra piezas para ajustar manualmente.
  5. Imprime el plano o guarda como PDF desde el menú de impresión del teléfono.
Importante: es un optimizador geométrico 2D para cortes rectangulares. No modela vetas, defectos, cantos, cortes no rectos ni secuencia física de la sierra. Verifica las medidas y el sentido de corte antes de producir.

Instalar en Android

Abre esta aplicación desde Chrome en Android, toca el menú ⋮ y elige Instalar aplicación o Agregar a pantalla principal. Para instalarla como PWA completa, debe servirse desde una dirección HTTPS.
